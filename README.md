# Sistem-Manajemen-Jamur

## Backend:

1. Buka folder backend\src\config\db.js
2. Ubah database connection sesuai dengan host, user, database, dan password
3. Open command prompt (CMD) dan buka folder backend
4. Jalankan perintah npm run start
5. Buka web browser, dan akses link berikut:

- Admin: http://localhost:3000/admin
- Petugas: http://localhost:3000/petugas

## Frontend:

1. Open command prompt (CMD) dan buka folder frontend
2. Jalankan perintah npm run dev
3. Open web browser, dan akses link berikut:

- Admin: http://localhost:5173/admin
- Petugas: http://localhost:5173/petugas
